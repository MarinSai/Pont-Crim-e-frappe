# Pont-Crim-e-frappe

Animation pour Le Grand Continent : la frappe ukrainienne contre le pont de Crimée (16-17 novembre 2026), en quatre étapes (le pont, le couloir, l'impact, le bilan).

Fichier unique `index.html` (français), prévu pour une intégration en iframe (hauteur automatique via iframe-resizer v5). Sources et outils de construction dans `sources/` (voir `sources/LISEZMOI.md`).
